# Official aged-care references

Downloaded 4 October 2026 from the Australian Government Department of Health, Disability and Ageing. These are reference materials for product discovery and workflow review; they are not universal mandatory nursing forms. Check the source page for newer versions before relying on them, and tailor use to provider category, setting, policy and applicable law.

| Local file | Use and scope | Official source |
|---|---|---|
| [QI data recording template (August 2026)](official-qi-program-data-recording-template-2026-08.xlsx) | Registered providers' single-home workbook for QI collection and GPMS reporting; measurements must follow the current Part A manual. | [Government resource page](https://www.health.gov.au/resources/publications/qi-program-data-recording-templates?language=en) |
| [National Aged Care QI Program Manual Part A (September 2026)](official-national-aged-care-qi-manual-part-a-2026-09.pdf) | Definitions and methods for collecting/submitting quality-indicator data. | [Government resource page](https://www.health.gov.au/resources/publications/national-aged-care-quality-indicator-program-manual-part-a-0) |
| [GP care-plan contribution template (August 2024)](official-care-plan-contribution-template-2024-08.pdf) | Six-page GP contribution/review template for residential aged-care incentive patients; a reference for structured fields, not a complete provider nursing record. | [Government resource page](https://www.health.gov.au/resources/publications/care-plan-contribution-template?language=en) |
| [Restrictive-practices consent FAQ (February 2026)](official-restrictive-practices-consent-faq-2026-02.pdf) | Official explanation of residential restrictive-practice consent and substitute decision-maker process; not a consent form. | [Government resource page](https://www.health.gov.au/resources/publications/consent-for-restrictive-practices-frequently-asked-questions) |

The public aged-care guidance is not a universal template library. Provider forms should be reviewed with nursing, privacy, clinical-governance and legal owners before adoption or translation into product workflows.
