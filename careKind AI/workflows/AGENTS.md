# Workflow definitions scope

Maintain task procedures and run records here. README.md maps inputs and output locations.

- Align procedures with `../rules/` and actual requested scope; a workflow does not grant external-action authorisation.
- Run records describe actual outputs/checks and unresolved work, never proposed work as completed.
- Raw feedback remains human/source-maintained. Workflow changes must not create automatic AI feedback entry.
- These definitions guide task-triggered execution; they are not background scheduling or evidence of live tool activation.
