# Shared skills

These are the maintained, tool-neutral skills used by both Claude Code and Codex. Edit instructions here and the linked workflow; the native adapters only route tasks and do not duplicate the procedures.

- `carekind-product-delivery` — requirements, app work and release preparation.
- `carekind-market-research` — competitor and market research.
- `carekind-compliance-research` — Australian law and official paperwork references.
- `carekind-operations` — company OS, team roles, internal operations and marketing drafts.
- `carekind-feedback-analysis` — explicit requests to analyse existing raw feedback without modifying it.

Native entrypoints: `../.agents/skills/carekind-workflow/SKILL.md` and `../.claude/skills/carekind-workflow/SKILL.md`. See `../workflows/README.md` for use and session-loading requirements.
