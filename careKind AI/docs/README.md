# careKind AI — 共用产品文档

此目录供运营、产品、开发及协作 AI 工具共同查阅。

核心需求依据：[careKind AI PRD](PRD_careKind_AI.md)。文档包含产品定位与发展方向、8 小时班次录音、老人归属、护理情况记录、人工审核、功能验收、产品逻辑、端到端工作流及团队协作流程。

Joanna 是 Product Owner。功能范围、优先级、验收条件和对外产品描述应与本 PRD 一致。提案与未验证目标应保留明确标记；开发证据放在 `APP Development/`，市场/法规资料放在 `Marketing & Operations/`。

创建或修订产品设计/PRD 时，执行 [产品与法律参考规范](../rules/product-and-legal.md)，实际查阅本地法律研究、合规登记册及相关官方参考文件，并记录依据与需求的映射。团队共同规范见 [rules](../rules/README.md)。

PRD 的原位置 `APP Development/product/` 已迁移；只维护本目录中的共用版本。
