# 用户反馈 — Feedback

此文件夹保存用户反馈的原始记录（raw）。

## 原始记录入口

[feedback.txt](raw/feedback.txt) 是空白原始反馈文件，供 Joanna 或团队成员手动录入真实用户反馈。当前没有录入任何反馈。

也可以在 `raw/` 下按日期保存独立文件，或直接放入收到的原始邮件、表单导出、截图等来源文件。

## 记录规则

- 原始反馈由团队手动录入或从来源系统直接导出；AI 不编写、润色、改写、翻译、总结或补全原始反馈。
- 保留用户原话，包括原有拼写、语气、语言和格式；不得加入推测、解释或虚构内容。
- 来源和收到时间等元数据可记录在 `metadata/` 下，与用户原文分开。元数据不得冒充用户反馈。
- 后续人工补充、更正或跟进另建记录，保留原始版本。
- 如日后需要分析或产品需求整理，先取得 Joanna 的明确指示，并保存到 `analysis/` 等单独位置；不得覆盖 `raw/`。

`raw/` 为人类和来源系统维护的原始资料区。自动化工具和 AI 应遵守 [AGENTS.md](AGENTS.md)。
