# Raw user feedback rules

These instructions apply to this Feedback directory and its descendants.

- `raw/` contains source material maintained by humans or exported directly from source systems. Do not create AI-authored feedback, edit, overwrite, paraphrase, polish, translate, summarise, complete, or delete raw feedback files.
- Do not invent feedback, speakers, source details, dates, or quotes. Empty raw files are intentionally awaiting human input.
- Do not insert AI annotations or analysis into raw files. Keep metadata and any authorised analysis outside `raw/`.
- Analyse feedback only when explicitly requested by Joanna/the user; save any requested output separately and preserve original sources.
- Changes to the feedback documentation or directory structure must preserve the raw source files.
